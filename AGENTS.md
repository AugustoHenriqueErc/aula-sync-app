# Orientações do projeto

O aula-sync-app também é um projeto de estudo.

## Forma de trabalho

- Comunicar-se em português.
- Explicar conceitos importantes antes de implementar.
- Trabalhar somente em uma etapa do roadmap por vez.
- Não antecipar funcionalidades de etapas futuras.
- Evitar abstrações desnecessárias.
- Mostrar como testar cada implementação.
- Não fazer commits sem solicitação.
- Preservar as alterações realizadas manualmente pelo desenvolvedor.

## Tecnologias

- Frontend: Svelte, Vite e TypeScript.
- Backend: Go com Fiber.
- Banco de dados: SQLite.
- Integração futura: Google Apps Script.
- Tailwind CSS é opcional.

## Arquitetura

- O SQLite será a fonte principal dos dados.
- A integração com o Google será adicionada depois do funcionamento local.
- Não utilizar microserviços, MongoDB, Kubernetes ou sistema de plugins.
- Manter frontend e backend separados durante o desenvolvimento.
